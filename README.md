# module01_environment
Цель проекта - освоить базовые навыки работы с GitHub Copilot и научиться создавать маленькую воспроизводимую проектную капсулу.
Проект состоит из трех файлов: README.md, data и notebook. Как их найти: 1) заходим в репозиторий module01_enviroment 2) открываем ветку main 3) перед нами все файлы проекта.
Как открыть файлы: 1) открываемм ветку main 2) выбираем нужный файл.
Проверка: чтобы проверить, что все работает в notebook, смотрим: что project.title создается до команды print(), нет ошибки NameError.
Ограничения: без персональных данных; без токенов; GitHub Classroom не используется; Git CLI не обязателен.
История версий - в version_log.md
